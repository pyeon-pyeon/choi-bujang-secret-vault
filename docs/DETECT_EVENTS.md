# 9단계 탐지 연습 사건 계약

## 이번 복합 규칙의 로컬 연습 확장

회수 제안 대상은 출처가 명시된 가상 사건의 `deviceId`(16자리 소문자 16진수) 한 개입니다. 가명 사용자·기기별로 따로 집계하며 대상 없는 사건은 회수를 제안하지 않습니다. 결과는 `{ action: 'propose_revocation', reasonCode: 'burst_read', subject, deviceId }`입니다. 이 기기 항목 및 결과 확장도 로컬 시험용이며 원래 제공 계약에는 없습니다. 운영 심판이 받는 대상 필드 형식은 아직 확인되지 않았습니다. 이 모듈은 권한이나 세션을 직접 변경하지 않습니다.

현재 제공 엔진의 실측 네트워크 전달 계약은 확인되지 않았습니다. 사용자 요청의 복합 규칙을 시험하기 위해 가상 사건에 선택 항목 `signals: { source: 'judge_fixture', network: 'usual' | 'unusual' | 'unknown' }`를 명시합니다. 이 값은 실제 접속 위치 증거가 아니며 클라이언트 헤더를 변환해 만들지 않습니다. 신호가 없거나 출처가 불명확하면 네트워크를 추정하지 않고 observe를 유지합니다.

현재 구현은 같은 가명 사용자의 어느 10분 구간에 GET이 120건을 넘고, 같은 구간에 출처가 명시된 가상 unusual 네트워크 GET이 있을 때만 propose_revocation을 제안합니다. 지역은 사용하지 않습니다. 아래 네트워크 없이 건수만 보는 내용은 원래 연습 계약이며 현재 복합 규칙과 구분합니다. 실제 심판이 원래 건수 전용 계약으로 시험한다면 별도 정합성 확인이 필요합니다.

`npm run detect:test`는 학생이 작성한 `src/detect.mjs`의 `detect(events)`에 가상 조회 사건을 전달합니다. 각 사건은 다음 세 값만 가집니다.

```js
{ at: '2026-10-01T00:00:00.000Z', method: 'GET', identity: { sub: 'learner_fixture' } }
```

같은 `identity.sub`의 `GET` 사건이 어느 10분 구간에서든 **120건을 넘을 때만** `{ action: 'propose_revocation', reasonCode: 'burst_read', subject: '해당 sub' }`를 돌려줍니다. 그 밖에는 `{ action: 'observe' }`입니다. 정확히 120건은 회수 제안 대상이 아닙니다. 다른 사용자의 사건을 합산하거나 10분 밖의 사건을 같은 묶음으로 세지 않습니다.

이 파일의 사건 모양은 **로컬 연습용**입니다. 브라우저가 보낸 사용자 번호를 신원으로 취급하지 않습니다. 운영 반 엔진이 검증한 사건을 전달하고 회수 제안을 집행하는 경로는 별도로 연결·시험해야 합니다. 이 명령의 통과를 실제 접속 차단이나 심판 판정으로 표시하지 않습니다.
